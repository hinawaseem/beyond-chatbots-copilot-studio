# Agent Instructions

This folder contains the Microsoft Copilot Studio agent instructions used in the AI Maitri Global Summit 2026 demonstration.

The project follows one agent through four iterations:

1. **Foundation:** Define the agent's responsibilities, reasoning behavior, and boundaries without providing supporting documents.
2. **Evidence:** Introduce five change-specific documents and evaluate how the agent identifies risks, dependencies, missing information, and contradictions.
3. **Governance:** Add the ECM-001 CAB Standard as an organizational knowledge source and assess applicable policy requirements.
4. **Hardening:** Refine the agent's instructions and reporting structure to improve clarity, consistency, and evidence traceability.

## Architecture Boundaries

- Instructions = Reasoning behavior
- Knowledge = Organizational rules
- Runtime attachments = Change-specific evidence
- Agent = Analysis
- CAB = Decision authority

## Important

This is an educational demonstration using fictional enterprise documents.

The agent does not approve or reject production changes. Final decisions remain with authorized human reviewers.
